# Student Grade Analyzer

I built this as my Week 1 internship project. It's a Python program that takes students' marks and turns them into a proper report card: totals, averages, grades, and who passed or failed.

## What it does
You tell it the subjects and how many students there are, then type in each student's marks. It checks that every entry is a valid number between 0 and 100, so a typo like "abc" or "150" won't break it. After that it prints a clean table and a class summary with the topper, the class average, and the average for each subject.

## Grading
- 90+ → A+
- 80+ → A
- 70+ → B
- 60+ → C
- 50+ → D
- 40+ → E
- Below 40 → F

A student needs at least 40 in every subject to pass. Even with a high average, failing one subject means Fail.

## What I practiced
Variables, data types, conditionals, loops, functions, lists, and dictionaries.

## How to run it
1. Open `student_grade_analyzer.ipynb` in Google Colab
2. Run the cells from top to bottom
3. Enter the subjects, the number of students, and their marks
